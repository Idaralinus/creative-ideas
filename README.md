# Creative Ideas — Furniture Portfolio

## Run in VS Code
1. Install Node.js (Node 20+ recommended).
2. Open this folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:
   npm install
5. Then:
   npm run dev
6. Open the localhost URL shown by Vite.

## Production
npm run build

## Edit
- `src/App.jsx` = page sections
- `src/components/` = reusable UI
- `src/data/projects.js` = portfolio projects
- `src/index.css` = global CSS
- `public/images/` = your local images

Replace the sample images, phone, email, WhatsApp number, address, social handle and testimonial before publishing.
This starter uses Tailwind CSS v4 with `@tailwindcss/vite`.
